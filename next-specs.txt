1
/speckit.specify I need a coffee brewing calculator that helps users determine the correct water amount based on their coffee weight and desired brewing ratio. Users should be able to input the amount of coffee they want to use (in grams) and adjust the coffee-to-water ratio (e.g., 1:15, 1:16, 1:17). The calculator should instantly display the total water amount needed. The calculations should update in real-time as users change either the coffee amount or the ratio. This is essential for consistent brewing results.

2
/speckit.specify I want users to be able to create and manage custom brewing methods for pour-over coffee. Each method should consist of multiple pouring steps, where each step has a water percentage (portion of total water) and a duration in seconds. Users need to be able to name their method, add a description, optionally categorize it, and define the pour pattern. The system should validate that all pour percentages add up to 100%. Users should be able to edit their custom methods and delete them. The app should come with several pre-configured default methods (like the 4:6 method and James Hoffmann's technique) that users cannot edit but can reference. Methods should be saved locally so they persist between sessions.

3
/speckit.specify Users need to browse and select from available brewing methods before starting their brew. The interface should display all available methods, both default (built-in) and custom (user-created), organized by categories. For each method, show the name, description, and if applicable, credit to the creator with a link. Users should be able to easily select a method which will then be used to generate the brewing steps. The selection should be visually clear, showing which method is currently active.

4
/speckit.specify Once a user has selected their coffee amount, water ratio, and brewing method, generate and display a step-by-step brewing guide. For each step, show the step number, the amount of water to pour for that specific pour, the cumulative total water amount up to that point, when to start the pour (time in minutes and seconds), and a description of what to do. The steps should be calculated based on the selected method's pour percentages applied to the total water amount. Include timing information for when each pour should occur. Display this in an easy-to-follow format that users can reference while brewing.

5
/speckit.specify Create an interactive brewing assistant that guides users through the brewing process in real-time with a timer. When users start brew mode, display a summary of their brew parameters (method, coffee amount, water amount, ratio, temperature). Include a prominent start button to begin the timer. Once started, show a timer that counts up from 0:00, display the current step with its details prominently, show how much water to pour to (cumulative amount), highlight the elapsed time, show progress visually with a progress bar, and preview the next upcoming step. The interface should automatically advance to the next step when the timer reaches that step's designated time. When the brew is complete (all steps finished), show a completion message and offer to save the session. The timer should be accurate and update every second.

6
/speckit.specify Users should be able to save their completed brewing sessions for future reference and replay them later. When saving a session, capture the coffee type or coffee selection, brewing method used, coffee amount, water amount, water temperature, total brew time, and timestamp. Display all saved sessions in a history view showing key details like date/time, coffee used, method, and amounts. For each historical session, provide a "Brew Again" action that loads all that session's parameters back into the calculator and method selection, allowing users to quickly replicate a previous successful brew. Sessions should be stored locally and persist between app sessions. Users should be able to see their brewing history sorted by most recent first.

7
/speckit.specify I want users to maintain a personal library of coffee beans and grounds they use. Users should be able to add coffee entries with details including brand name, coffee name, description, roast level (light, medium, or dark), and type (beans or ground). The app should come with some default coffee entries that users can reference but cannot edit or delete. Users can create their own custom coffee entries which they can fully edit and delete. For default coffees that users like, provide a duplicate function to create a custom copy they can then modify. Organize the coffee library by brand, with the ability to expand/collapse each brand to see its coffees. Display coffee cards showing all the key information and the appropriate action buttons (edit/delete for custom, duplicate for defaults). The library should persist locally so users don't lose their coffee collection.

8
/speckit.specify Add the ability for users to select a specific coffee from their library and set a water temperature for their brew. Provide a selector for choosing from available coffees in the library, and a temperature input or selector for setting the brewing water temperature in Celsius. Common temperatures for pour-over coffee range from 85°C to 96°C. Display the selected coffee and temperature prominently. This information should be included when saving brewing sessions so users can track what temperature worked well for specific coffees. The temperature should be optional but encouraged for better brew tracking.
